# Sitebook demo

Live demo of Sitebook, Townline's in-house construction management platform prototype.

**Open the demo:** https://townline-construction.github.io/sitebook-demo/

- Sample data only. Nothing you enter is saved; it resets when the page reloads.
- Use **Viewing as** at the top to switch between Townline staff and an external trade partner.
- Try **Coordination issues** and click a location chip to jump to the issue in the 3D model or on the drawing.

Sample 3D models: buildingSMART International "Simple Scene" (CC BY 4.0). 3D viewer built on three.js and web-ifc.

This repository holds only the built demo. The source code lives in a private repository.
